## Manufacturer notice

These messages change how your Lumatone works at a low level. Wrong values can leave keys unplayable or make the keyboard inoperable. Changing settings with SysEx messages voids your warranty, and Lumatone technical support is not available for keyboards whose function has been damaged by changing these settings. The format of the SYSEX message is the same as the transmitted message with the inclusion of the response status byte located after the command byte. The response status byte ranges from 0x00 to 0x04:
00h – NACK. The transmitted command was not recognized
01h – ACK. The transmitted command was processed successfully
02h – BUSY. The transmitted command was not processed as it is currently processing the previous transmitted message.
03h – ERROR. The transmitted command was not processed due to invalid data or board ID byte parameters or message length.
04h – STATE. The transmitted command was not processed due to the keyboard not being in the correct operating state. See
Calibrate Aftertouch (0Fh)

and

04h – LIST FULL (

Set Key Parameters (00h)
.
The data bytes for the response message are dependent on the specific command transmitted.

## 00 Set Key Parameters

This command is used to configure a specific key’s note, channel, and type parameters.
In firmware version 1.3, the response returns 04h if the maximum amount of faders has already been reached. The maximum amount of faders for the keyboard is 15 faders. If this scenario occurs, one of the faders on the keyboard must first be assigned back to a note first to decrement the internal fader list index. To determine the keyboard’s current key type setup, the command
Get Type Configuration (0x18h)
can be used to read the key set up. More information regarding this command is in
Get Type Configuration (18h)
.
In document version 1.4, response packet 04h has been deprecated since fader polyphony limitations are performed on the go rather than a static maximum limit.
In firmware version 1.0.11 (documentation version 1.13), an extra key type was included: 00h Key Disabled.
Software variables affected include the following:
Key Channel values
Key Note or CC values
Key operating type
CC polarity values

## 20 Set Velocity Intervals

This command is used to configure the velocity interval data array for the Lumatone keyboard. The data array is composed of 127 12-bit variables which are used to map a range of time to a region index. Each increment of this velocity interval value represents ~1.1ms. In order to comply with the MIDI protocol, each 12-bit value is split into two 6-bit variables in the SYSEX message. The order of each interval mapping value must be greater than the previous value, up to 2048.

## 55 Set Colours

This command sets the colours of all 280 keys (board ID 00h) or of the 56 keys of one board (board ID 01h-05h) in a single message, for fast or animated lighting. ## Velocity Curve Mapping

The Lumatone keyboard uses a time of flight methodology to determine the velocity instead of the conventional pressure sensor. Each board scans the ADC positioning of all its keys every 1.1 milliseconds. The board records how many intervals the key takes to travel between key release and depressed events. This is known as dwell ticks.
The Lumatone keyboard uses two data arrays, the velocity look up table and the velocity interval table, to map the dwell ticks to the final midi output velocity during a Note event. These tables can be configured via the SYSEX commands 0x08h and 0x20h.
When a Note event is being processed, the tick value is compared to the velocity interval table. The velocity interval table is a 127 12-bit array which determines the region where the dwell tick lies. Each 12-bit represents the maximum time of each region. Interval [0] represents the first node above 0ms while Interval [126] represents the last node before the maximum ticks which is 2048. Note that the data in the array must be configured with each such that index 0 contains the lowest amount of ticks and subsequent increments should be continue to be a greater value than the previous up to a number of 2047.
